# Coverage of the original editing brief

| Requested outcome | Operational | Partial, unavailable or externally gated |
| --- | --- | --- |
| Inspect a reference | Native-rate decoded frame metrics, timestamped picture changes, audio level, local acoustic classifications and temporal evidence | Reduced spatial resolution and representative-frame semantics. Shot, transition and global camera classifications are estimates. Arbitrary masks, graphics, animation curves, lighting setups and narrative purpose cannot be reconstructed reliably. |
| Learn an executable style | Multi-reference fusion, adaptive cadence, shot duration, framing, caption layout and color, music preferences, editable parameters, local versions and previews | Font identification, complex motion design, long-form story structure and emotional exceptions have limited or heuristic coverage. |
| Edit one or more uploads | Browser runs the director, uses speech timing and shot boundaries, makes cuts, creates captions, chooses supported effects, renders MP4 and exports editable JSON and OTIO in three aspect ratios | Human-level take selection, dramatic structure, arbitrary graphics, multilingual alignment quality and predicting audience retention need further work. Native Remotion composition is vertical. |
| Illustrate a story | Licensed stills, a moving stock cutaway, literal phrase selection, negative terms, visual recognition and generated percentage graphics | Registry search uses curated semantics. External stock and voice providers require credentials and rights. Local ComfyUI requires a licensed checkpoint. Prompt-to-video has no validated production path. |
| Picture, sound and effects | Adaptive zoom, transition rules, tracked frontal faces, keyed screen replacement, portrait alpha masks, native LUTs and local acoustic events. Source music preservation and targeted speech-mix revision | General moving-object selection, occlusion handling, depth, relighting, full audio source separation and musical arrangement remain partial or unavailable. |
| Searchable assets | All fifteen categories have typed entries, license information and previews. Supported runtime and adjustable properties are identified per asset. | The shipped library is small. Some entries are specific to Remotion or native FFmpeg. Commercial asset catalogs require separate entitlements. |
| Tool registry | MCP exposes reference analysis, template fusion and revision, source inspection, portrait masks, clip operations, timeline edits, generation adapters, rendering, checks, memory and OTIO. Related operations share typed commands. | General object tracking, voice generation without an authorized provider, and unbounded creative tool use are unavailable. |
| QA and revision | Post-encode decode, cut/timing and picture checks, caption OCR samples, delivery-channel peak counts, speech/music comparison, targeted repair, configurable pass limit and rollback | Sampled OCR and acoustic confidence cannot establish whole-film legibility, intelligibility, semantic correctness or artistic quality. Audience retention has no validated prediction model. |
| Memory and feedback | Style evidence and versions, decisions, local QA histories, positive and negative choices, retrieval for related edits, approved source/edit playback | On-device storage is quota-limited. Preferences are retrieved rather than fine-tuned. General learning from implicit approval and across devices is incomplete. |
| Running the system | Single-link private browser app, local native pipeline, CPU fallback, caches, isolated model runtimes, native resume, non-destructive exports and backend-only provider keys | Physical GPU, Windows, remote cloud render fallback and live paid integrations still need qualification. The hosted editor processes videos on the user’s device. |
| Professional acceptance | Real decoded exports, inspectable reports, licensed images and observational solar footage, independent pixel checks, format checks, functional tests and measured runtimes | No edited reference and corresponding raw footage from the owner have been provided. Matching their taste requires comparative review using those videos. |
