# Director validation

The browser learns English text geometry on device using Tesseract.js 6.0.1, its LSTM WebAssembly core and bundled English weights. The model, worker and OCR runtime come from the editor’s origin. The JavaScript packages carry Apache-2.0 notices and the data package identifies its packaging as MIT. English OCR may miss stylized text. A six-frame sample cannot identify every cue or establish exact font identity. Contrast is a local luminance estimate between the 10th and 90th percentile inside a detected line. [Tesseract.js API](https://github.com/naptha/tesseract.js/blob/master/docs/api.md) · [Language data](https://github.com/naptha/tessdata)

A headless Chromium session learned the changing “MORNING LIGHT” and “QUIET FOREST” cards at 0.25–2.75 seconds. The midpoint of the measured text band was about 71% of frame height. The same session edited the narrated sample with the learned template, saved a still-camera preference, reloaded the editor and rendered again. The exported scene instructions had unit scale and zero programmed zooms. The OCR quality report sampled three of eleven final caption cues. Some cues required review after the allowed revision. [Reference fixture](../examples/verified-browser/ocr-cards.mp4) · [Measured lines](../examples/director-feedback/caption-measurements.json) · [Edited preview](../examples/director-feedback/learned-preview.jpg)

The chroma-screen fixture is a six-second moving red rectangle on a green surround. The browser sampled foreground centers at 4 Hz and cropped and composited the source at 30 fps. Its full-resolution vertical export contains 180 frames. An independent pixel check at 0.35, 2.8 and 5.5 seconds found background RGB (38,50,74) and a subject center between 46.5% and 47.1% of the output width. Reflective clothing, multiple subjects and ordinary backgrounds may prevent useful tracking. Screen replacement is opt-in. The editor abstains when it cannot establish a consistent screen. [Input](../examples/director-feedback/screen-source.mp4) · [Export](../examples/director-feedback/reframed.mp4) · [Tracking measurements](../examples/director-feedback/screen-timeline.json)

The local MCP tool process_project_media writes a new PNG or H.264 file for frame extraction, trimming, static reframing and .cube LUT application. FFmpeg integration tests create and decode actual outputs. Separate tests cover out-of-project paths and invalid time ranges. The original media stays intact. The generated-media tools require the native project environment.

The editor stores up to 200 explicit preferences and the latest 30 edit and feedback records in IndexedDB. The history download contains source names, editing decisions, QA and links between successive edits. The source pixels remain in the local browser project. Human validation on the owner’s reference and raw footage is pending.

One Linux CPU Chromium run took 2.4 seconds for reference learning. The draft reference-guided edit took a further 21.3 seconds. Reloading and exporting the standard-resolution edit took a further 31.1 seconds including feedback entry. The six-second screen fixture and download took another 7.4 seconds. These are single-run observations. Run scripts/check-browser-director.py against the built studio with Playwright and Chromium to repeat the flow.

## Moving portrait

The browser used the bundled pico frontal-face cascade on a six-second moving NASA portrait. The sampled horizontal face center moved from 23% to 67% of the widescreen input. Independently running OpenCV's frontal-face Haar cascade on three decoded vertical output pictures found the face between 46.5% and 47.6% of frame width. The original face spanned 26.1% to 65.2% across those three times. The director avoids tracking intervals with competing faces or missing detections. Profiles, occlusions and very small faces can be missed. [Source](../examples/face-framing/source.mp4) · [Vertical render](../examples/face-framing/vertical.mp4) · [Tracking measurements](../examples/face-framing/observations.json)

## Picture motion, illustrations and recovery

The browser compares up to 160 reduced-resolution pictures for translation and scale. A match must improve the fit in at least three image quadrants. It discards comparisons that cross detected cuts. On the three-second mountain zoom fixture it measured 11 supported comparisons and inferred outward motion. A reference majority for pullbacks changes the direction of eligible camera moves in the next edit. This estimates global image transforms. It cannot uniquely distinguish a physical camera move from a digital crop or coordinated object motion. [Input](../examples/illustrations/zoom-out-reference.mp4) · [Timestamped observations](../examples/illustrations/zoom-out-observations.json)

When a retained phrase states an exact percentage of a whole, no licensed stock image matches and motion is enabled, the director can generate a timed proportional graphic locally. The bar in the rendered example fills to the 64% named in the supplied test subtitle. [Rendered excerpt](../examples/illustrations/proportion.mp4) · [Plan](../examples/illustrations/decision.json)

The native studio stores its local editing intent before acknowledging the request. On restart it resumes eligible local jobs, preserving the edit identifier and cached ingest and analysis stages. The test interrupted the server immediately after it accepted a six-second fixture, restarted it, and verified a playable 180-frame MP4 with the same edit identifier. The native renderer probes an actual one-frame encode before enabling the H.264 hardware path. On this machine FFmpeg listed NVENC but the driver was unavailable. The CPU fallback produced the final MP4 in 51.8 seconds. Windows and GPU hardware still require independent testing. A signed-in Claude director job needs an explicit retry after interruption.

Reference OCR also estimates ink when the surround is sufficiently uniform and at least 65% of sampled caption lines agree on a recurring fill. The case rule requires consistently uppercase changing text. The browser abstains on inconsistent ink, and mixed-case captions retain the source transcript’s case. Native MCP tools direct_timeline and render_timeline apply validated instructions for camera moves, graphics, transitions, clip replacement, captions and audio. The rendering tool uses a separate workspace per invocation. A real six-second native variant contained 180 frames and preserved the previous export.
